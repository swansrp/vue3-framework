# 框架常用组件说明

> 适用范围：所有基于 portal-framework 的业务项目。开发时**优先使用框架组件，避免重复造轮**。
> 本文是组件目录（catalog）；Portal 深入用法见同目录《PORTAL组件使用指南.md》。

## 注册机制（先读这个）

- 组件由 **`unplugin-vue-components` 自动注册**（配置：`src/framework/config/vite.config.ts`，dirs 含 `src/framework/components`，dts 产出 `src/components.d.ts`）——**全部无需 import，直接写标签**。
- 命名规则：`Xxx/index.vue` → 目录名 PascalCase；子文件 `foo/Bar.vue` → `<Bar>`。
- 例外：`<Icon>` 是手动全局注册（渲染后端返回的 antdv 图标字符串名）：`<Icon :icon="'UserOutlined'" />`。
- **类型/契约必须手动 import 路径**：`Portal/type.ts`（`QueryType`、`FILTER_TYPE`、`UploadModalType`、`PortalBindType`）、`AdvancedSearch/ConditionList/type`（`ConditionListType`）、`chartConfig/types`（`DashboardItem`）、`agentStages/types`（`AgentStageItem`）、`ResourcePerm/types` 等。
- 全局 provide：`upload` / `download`（main.ts 注入，UploadFile/Multimedia 内部使用）。

## 一、布局

| 组件 | 用途与关键接口 |
|---|---|
| `<ContentLayout>` | 左右分栏骨架（侧栏+可拖分隔条+内容区）。slots `#side`/`#content`；props `width`(默认200)/`height`。任何"左树/左列表+右业务"页面用它 |
| `<NavigationFramework>` | 应用外壳全套：顶栏`<TopHeader>`、面包屑搜索`<CrumbSearch>`、历史页签`<HistoryTab>`、左/顶/次级导航、底栏。业务项目直接放壳组件 |
| `<Drawer>` | 自实现左/右抽屉（边缘拖拽改宽、ESC 关闭，非 antdv）。props `visible/title/width/placement('left'|'right')` |
| `<Loading>` `<Watermark>` `<CopyrightIcp>` `<DarkTable>` | 全屏加载占位；页面明/暗水印（config 与 userStore 合并）；ICP 页脚；暗色"侧栏+表格"大屏壳 |

## 二、数据展示

| 组件 | 用途与关键接口 |
|---|---|
| `<Portal>` | **框架最核心组件**：配置驱动的动态表工作台（表树+list/grid/tree 三模式+行内编辑+高级筛选+导入导出+绑定Tab）。核心：`tableId`+`query` 注入；`emits: configLoaded/selectedData/dataChanged`；`expose: queryData()/getData()/addRow()/openUploadModal()` 等；10+ 作用域插槽（`header-action`/`action`/`add`/`view`…）。详见《PORTAL组件使用指南.md》 |
| `<SurelyTable>` | `@surely-vue/table` 轻薄封装（Excel 式大数据表），props `columns/dataSource/tableHeight/summaryList`，emits `pageChange/handleSearch`。Portal 之外的表格首选 |
| `<leftListRightTable>` | **左分类列表(可搜)+右表格+分页**固定模板。props `columns`、`updateTableFlag`(外部自增触发重载)；slots `top_btn_list`/`table_btn_list`。字典/分类管理页标配 |
| `<WideTableView>` | 动态宽表（列=属性、行=产品）。props `productSelectFn`/`fixedColumns` 必传、`configApiPrefix`(默认/form/widetable)、`isEmbedded` |
| `<GeneralDashboard>` | 多表指标仪表盘（手风琴+指标树+栅格）。props `tableConfigs: TableConfig[]`(必)、`globalConditions`、`gridColumns` |
| `<DictContent>` `<Marquee>` `<Swiper>` `<Multimedia>` `<SvgIcon>` | 字典选择内容区（tree/list 两态）；超长文本无缝滚动；图片轮播；单元格图片/视频预览+上传缩略；svg-sprite 图标 `#icon-{name}` |
| Portal 子模块 | `PortalTreeMode/PortalListMode/PortalGridMode`、`PortalEditModal/PortalViewModal/PortalAdvancedSearchModal/PortalUpload`、大屏 `Dashboard/IndicatorTreePanel/ConfigPanel` 等 32 个均已注册，可单独复用 |

## 三、表单与选择

| 组件 | 用途与关键接口 |
|---|---|
| `<SearchSelect>` | **通用搜索下拉三合一**：① `api-fn` 远程防抖搜索(值回显自动回查)；② `options` 本地过滤；③ `create-fn` 原地新建(出现"＋"，建档自动选中，`emit('created')`)。关键 props `valueField('id')/labelField('name')/searchProperty('name')/pageSize(50)`；扩展字段用默认插槽。配合 `src/components/quickCreate.ts` |
| `<AdvancedSearch>` | 服务端条件构建器（AND/OR+条件行）。props `columns`(必)/`condition`/`advanced`；`emit('getCondition', ConditionListType)`。Portal 高级筛选即它 |
| `<DynamicForm>` | schema 驱动动态表单工作台（分节导航+模块步骤+草稿审批）。props `formCode/formId/mode('fill'|'approve')/status('0'~'3')/lazyCreate`；emits `submit/saved/approve/reject`；expose `handleSaveAll()/handleSubmit()/handleApprove()` |
| `<Dict>` `<DictCodeSelector>` `<DictItemsManager>` | 字典下拉+管理入口。`<Dict>` props `dictCode`(必)/`parentCode`级联/`multiple`(逗号串)/`isManageMode`/`entityId`；emits `change(value, BizDictVO)`；expose `refresh()` |
| `<Staff>` `<DepartmentAndStaffSelect>` | 员工搜索下拉；部门+员工组合选择（`staffListValue`/`departmentListValue` 双 v-model） |
| `<DragGrid>` | v-model 栅格拖拽布局（大屏/看板摆放）。props `width/height/maxCol(12)/rowHeight/isDraggable`；expose `forceUpdate()` |
| `<MsgCode>` `<Dropdown>` `<LockSwitch>` `<DeletePopConfirm>` | 图形码+短信倒计时登录块；大屏风格下拉；编辑保护开关；表格行删除二次确认 |

## 四、上传与异步任务

| 组件 | 用途与关键接口 |
|---|---|
| `<UploadFile>` | 上传弹窗全流程：选文件(可 Excel 模板下载/解析)→上传→轮询进度→步骤条→确认。props `upload(缺省走provide)/template/progress/url/multiple/directory(整目录)/excelParseUrl`；expose **`showUploadDialogBox()`**；emits `uploadComplete/afterConfirm` |
| `<AsyncProcess>` | 通用异步任务进度弹窗（步骤：请求→校验→处理；总进度/已耗时/预计剩余/失败原因/日志）。**唯一必传** `progress: () => Promise<{step,total,percent,failedReason,logs,...}>`；expose `show()/updateProgress()`；`emit('afterConfirm')` 后父组件刷新 |
| `<AgentStages>` | **AsyncProcess 的泛化**——Agent 阶段步骤条：`pending/running/ok/error/skipped/stopped` 六态、每段实耗+全局预计剩余、可选停止按钮与日志滚底。props `stages: AgentStageItem[]`(必)/`logs`/`plan`(待办作细粒度基线)/`startedAt`；`emit('stop')`。数据源：session `/status` 轮询或 flow trace 节点映射 |

## 五、AI 对话

| 组件 | 用途与关键接口 |
|---|---|
| `<AgentChat>` | Agent 会话过程可视化壳。props `sessionId`(必，变化自动重置轮询)/`renderers`(事件type→业务组件)；emits `restart/finished(kind)/confirmation-revised`；内部 `useAgentSession` 增量拉 events |
| `<AgentChatPanel>` | 可复用"输入框+消息流"面板（chatbi 直接引用）。事件子件：`<AskSteps>` `<AskThinking>` `<AskClarifyCard>` `<AskPlanChecklist>` |
| `<Chatbi>` | 智能问数（自然语言→指标路由→图表/表格）。props `tableId`(不传=全局路由模式)/`gridColumns`/`tableHeight`；复用 Agent 流 + `specMerge` 图表装配 |
| `<SkillWorkbench>` | Agent 技能 flow 编排+评价工作台。props `skillCode/title/api: SkillWorkbenchApi`( nodes/edges 图结构 )/`flowMeta`/`extraTabs`；依赖 `@vue-flow/core` |

## 六、弹层

- `<DialogBox>`：统一风格弹窗（图标标题栏/可拖拽/可全屏/可选页脚），props `visible`(v-model)/`title/draggable/isFull/footer`；`<DarkDialog>` 暗色版。框架内业务弹窗底座。
- `<IconModal>`+`<IconList>`：图标选择弹窗（菜单/Portal 配置用）。

## 七、权限

- `<ResourcePermManager>`：资源权限配置弹窗（正向"对哪些资源给什么权"+反向"谁能看"双 Tab）。props `visible/resourceType/resources(必)`/`fieldNames`；类型在 `ResourcePerm/types.ts`
- `<UserPermission>`：用户组/部门维度可见性设置（与上互补：一个按资源、一个按主体）
- `<GroupManage>`：用户组管理页（`userGroupTypes` 控制单类直跳/多类列表，插槽塞业务 Tab）

## 八、图表与富文本

- `<UniversalChart>`：echarts 统一渲染器，`chartType`: `bar/line/ptLine/pie/metricsPie/treeStackedBar/rankingBar/comparisonBar`；props `dataMetrics`(必)/`categories`/`sortOrder`；`emit('click')` 下钻。子件 `<BarChart><LineChart><PieChart><MixedChart>`。
- `<ChartConfig>`：指标体系+看板配置工作台（指标树+卡片栅格+批量编辑）。props `tableId/permissions/useCommonDashboard`；expose `refreshDashboard()/loadDashboardData()` 等。
- `<TiptapEditor>` / `<TiptapToolbar>` / `<TiptapViewer>`：富文本编辑/工具栏/只读渲染（表格、任务列表、代码高亮、导出 PDF 全套扩展）。props `content|contentHtml/readonly/minHeight/exportPdf`；expose `getJSON()/getHTML()/setContent()`。

antd-vue + icons（全局底座）｜`@surely-vue/table`（Portal/SurelyTable，main.ts 已 `app.use(STable)`）｜echarts（chart/Portal）｜`@tiptap/*`+lowlight（编辑器）｜`@vue-flow/core`（SkillWorkbench）｜swiper｜dayjs｜lodash｜pinia（dictStore/useTreeStore/useUserStore）

## 开发建议

1. **先查本目录再造组件**；拿不准看 `src/components.d.ts` 全量注册名单。
2. 列表页 = `<Portal>` 或 `<SurelyTable>`+`<AdvancedSearch>`+`<SearchSelect>`；左树右表 = `<ContentLayout>` 或 `<leftListRightTable>`。
3. 长任务反馈 = `<AsyncProcess>`（后端出 progress 结构）或 `<AgentStages>`（六态阶段）；批量导入 = `<UploadFile>`。
4. 选人/选部门/选字典 = `<Staff>`/`<DepartmentAndStaffSelect>`/`<Dict>`，不要自己写下拉。
